# After Hours Words

A small vocabulary trainer for English words caught on YouTube. Each word has a plain-English meaning, workplace example sentences, and a usage tip. Review mixes multiple choice, fill-the-gap, recall, and write-your-own-sentence cards, scheduled with spaced repetition.

Open it at https://rybnikovveniamin.github.io/after-hours-words/ and, on an iPhone, add it to the Home Screen from the Share menu.

- Progress is stored in the browser on each device. Copy a backup in the Add tab to move it.
- The word list ships in `words.json`. New words added there appear on every device on the next visit.
- Sentence checks are optional. They use Claude Haiku 5.5 with your own Anthropic API key, stored only on your device.
